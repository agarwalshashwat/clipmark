# Launch Go/No-Go Checklist

## 48 Hours Before Launch
- [ ] `ci-unit`, `ci-extension-smoke`, and `ci-webapp-visual-smoke` passing on `main`.
- [ ] Full manual regression checklist completed from `CHECKLIST.md`.
- [ ] No open Sev-1 or Sev-2 defects.
- [ ] Dodo product IDs and webhook secret verified in production env.
- [ ] Supabase service-role and database connectivity validated.
- [ ] Extension package and Chrome Web Store assets finalized.

## 24 Hours Before Launch
- [ ] Test paid upgrade path end to end in production mode.
- [ ] Confirm Pro entitlement updates on purchase and cancellation paths.
- [ ] Validate referral and affiliate attribution on checkout flow.
- [ ] Confirm support mailbox and incident channel are staffed.

## Launch Approval
- [ ] Engineering owner sign-off.
- [ ] Product owner sign-off.
- [ ] Support owner sign-off.
- [ ] Rollback owner assigned.
- [ ] Launch timestamp agreed and communicated.
